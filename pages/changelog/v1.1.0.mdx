### LoroDoc

- `forkAt(frontiers: Frontiers)`: 在给定的 frontiers 处 fork 文档。
- `getChangedContainersIn(id: ID, len: number)`: 获取在给定 ID 范围内修改的容器 ID。

### LoroText

- `getEditorOf(pos: number)`: 获取给定位置文本的编辑器。
- `push(s: string)`: 将字符串推送到文本末尾。


### LoroMap

- `getLastEditor(key: string)`: 获取给定条目上最后一个编辑器的 peer id

### LoroList

- `getIdAt(pos: number)`: 获取给定位置列表项的 ID。
- `pushContainer(child: Container)`: 将容器推送到列表末尾。

### LoroMovableList

- `getCreatorAt(pos: number)`: 获取给定位置列表项的创建者。
- `getLastMoverAt(pos: number)`: 获取给定位置列表项的最后一个移动者。
- `getLastEditorAt(pos: number)`: 获取给定位置列表项的最后一个编辑器。
- `pushContainer(child: Container)`: 将容器推送到列表末尾。

### LoroTree

- `toJSON()`: 获取 LoroTreeNode 的 JSON 格式。
