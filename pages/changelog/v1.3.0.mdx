## 新增

- UndoManager 的 `onPush` 现在可以访问更改事件。
- 为每个容器添加 getShallowValue。

### LoroDoc

- `toJsonWithReplacer(replacer: (k, v)=>Value)`: 使用自定义替换函数将文档转换为 JSON 值。
- `revertTo(frontiers: Frontiers)`: 将文档恢复到给定的 frontiers。
- `findIdSpansBetween(from: Frontiers, to: Frontiers)`: 查找 `from` 版本和 `to` 版本之间的操作 id 范围。
- `exportJsonInIdSpan(idSpan: IdSpan)`: 导出给定 [`IdSpan`] 中的可读 [`Change`]。
