我们非常激动地宣布 Loro v1.0 的发布，这是一个重要的里程碑。

它具有稳定的编码格式、更快的文档导入和导出速度、更好的版本控制功能以及浅快照。有关更多信息，请查看[博客](https://loro.dev/blog/v1.0)。

以下是具体的 API 更改：

## 新增

### LoroDoc

- `getChange(id: ID)`: 通过 `ID` 获取 `ChangeMeta`。
- `setDetachedEditing(flag: boolean)`: 启用分离模式下的编辑，默认禁用。
- `isDetachedEditingEnabled()`: 分离模式下的编辑是否已启用。
- `setNextCommitMessage(msg: string)`: 设置下一次提交的提交消息。
- `shallowSinceVV()`: 文档仅包含此版本之后的历史记录。
- `shallowSinceFrontiers()`: 文档仅包含此版本之后的历史记录。
- `export(mode: ExportMode)`: 根据指定的 ExportMode 导出文档。更多详情请参阅[此处](/docs/tutorial/encoding)。
- `getDeepValueWithID()`: 获取带有容器 ID 的文档的深层值。
- `subscribeLocalUpdates(callback:(bytes: Uint8Array) => void)`: 订阅本地编辑的更新。
- `getPathToContainer(id: ContainerID)`: 获取从根到容器的路径。
- `JSONPath(jsonPath: string)`: 对 LoroDoc 执行 JSONPath。
- `forkAt(frontiers: Frontiers): LoroDoc`: 在指定版本 (Frontiers) 创建一个新的 LoroDoc
- `getPendingTxnLength():number`: 获取待处理事务中的操作数。
- `travelChangeAncestors(ids: ID[], callback: (meta: ChangeMeta)->bool)`: 按顺序遍历所有更改，包括输入 id，如果回调返回 false，则停止遍历。

### LoroText

- `updateByLine(text: string)`: 像 git 一样，逐行根据提供的文本更新当前文本。

### LoroList

- `toArray(): ValueOrContainer[]`: 获取列表的元素。如果值是子容器，则返回相应的 `Container`。
- `clear()`: 删除列表中的所有元素。

### LoroMovableList

- `toArray(): ValueOrContainer[]`: 获取列表的元素。如果值是子容器，则返回相应的 `Container`。
- `clear()`: 删除列表中的所有元素。

### LoroMap

- `clear()`: 删除 map 中的所有键值对。

### LoroTree

- `enableFractionalIndex(jitter: number)`: 设置是否为树位置生成小数索引。
- `disableFractionalIndex()`: 当您不需要对树的兄弟节点进行排序时，禁用树位置的小数索引生成。小数索引将始终为默认值。
- `isFractionalIndexEnabled()`: 树是否启用了小数索引生成。
- `isNodeDeleted(id: TreeID)`: 如果节点不存在，则返回 `undefined`，否则如果节点已删除，则返回 `true`。
- `getNodes(prop: getNodesProp): LoroTreeNode[]`: 获取森林的扁平数组。如果 `with_deleted` 为 true，则将包括已删除的节点。

### UndoManager

- `clear()`: 清除 `UndoManager` 的撤销和重做堆栈

## 变更

### LoroDoc

- 将 `setFractionalIndexJitter()` 移动到 `LoroTree`，您可以为每个 `Tree Container` 设置是启用还是禁用它。
- `import()`、`importWith()` 和 `importJsonUpdates` 将返回 `ImportStatus`，以指示哪些操作已成功应用，哪些操作正在等待。
- 新的事件订阅。
- 在 Loro 1.0 中，即使操作尚未提交，`doc.version()` `doc.frontiers()` `doc.oplogVersion()` 和 `doc.oplogFrontiers()` 也表示所有操作的最新版本。
- 将 `Loro` 重命名为 `LoroDoc`。

### LoroTree

- `contains(id: TreeID)`: 即使节点存在于内部状态中并已被删除，也返回 true。
- `nodes()`: 现在将包括已删除的节点，您可以使用 `isDeleted()` 进行过滤。
- `toJSON()`: 现在使用分层方法来表示树结构。

## 弃用

### LoroDoc

- `exportFrom(version)` 和 `exportSnapshot()` 已被弃用，请改用 `export(mode: ExportMode)`。
