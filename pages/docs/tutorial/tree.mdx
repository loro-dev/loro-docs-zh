# 树（Tree）

在需要使用层级数据结构，甚至跨层级移动节点的场景中，树结构尤为关键。Loro 基于 Kleppmann 等人在论文 **_[A highly-available move operation for replicated trees](https://martin.kleppmann.com/2021/10/07/crdt-tree-move-operation.html)_** 中提出的算法，实现了“可移动树”CRDT。

此外，Loro 还引入了 **Fractional Index**（分数索引）来为每个子节点排序，确保兄弟节点保持稳定顺序，从而提供 `moveAfter()`、`moveBefore()` 等 API。这在需要自定义排序的层级视图时非常实用。

## 节点数据

Loro 为每个树节点关联了一个 [Map](https://www.loro.dev/docs/tutorial/map)，作为节点的数据容器，你可以在其中嵌套 Loro 支持的任意结构。

> 注意：在 Loro 文档层级中，树节点关联的 Map 容器被视为 Tree 容器的子节点。

可以通过 `LoroTreeNode` 的 `.data` 获取关联的 map，然后调用 `set` 或 `setContainer` 向节点添加数据或子容器。例如：

```ts twoslash
import { LoroDoc, LoroTree, LoroTreeNode, LoroMap, LoroList } from "loro-crdt";
// ---cut---
let doc = new LoroDoc();
let tree: LoroTree = doc.getTree("tree");
let node: LoroTreeNode = tree.createNode();
node.data.set("key", "value");
node.data.setContainer("list", new LoroList());
```

## 有序的树节点

在图形设计、文件系统等需要兄弟节点有序的场景中，Loro 通过 `Fractional Index` 来实现。你可以在 [Figma 博文](https://www.figma.com/blog/realtime-editing-of-ordered-sequences) 中了解更多。简单来说，`Fractional Index` 会为每个对象分配可排序的值，如在两个对象之间插入新对象时，其索引值会位于左右邻居之间。我们基于 Drifting-in-Space 的 Rust 实现 [fractional_index](https://github.com/drifting-in-space/fractional_index) 做了扩展，以便在 Loro 中使用。

当新建或移动树节点时，Loro 会根据目标位置生成 `Fractional Index`，以便在兄弟节点之间排序。在协同环境下，可能出现多个节点拥有相同 `Fractional Index`、或新节点计算出的索引与左右邻居相同等冲突情况，我们在[博客文章](https://www.loro.dev/blog/movable-tree)中详细讨论了处理方案。

需要调用 `enable_fractional_index(jitter: number)` 来启用 `Fractional Index`。

> 注意：Fractional Index 可能出现交错（interleaving）问题，但对于树结构我们认为是可接受的。

## 事件

树结构包含三类事件：`Create`、`Move`、`Delete`，定义如下：

```ts no_run twoslash
import { TreeID } from "loro-crdt";
// ---cut---
export type TreeDiffItem =
  | {
      target: TreeID;
      action: "create";
      parent: TreeID | undefined;
      index: number;
      fractionalIndex: string;
    }
  | {
      target: TreeID;
      action: "delete";
      oldParent: TreeID | undefined;
      oldIndex: number;
    }
  | {
      target: TreeID;
      action: "move";
      parent: TreeID | undefined;
      index: number;
      fractionalIndex: string;
      oldParent: TreeID | undefined;
      oldIndex: number;
    };
```

其中 `index` 表示节点的顺序位置，`fractionalIndex` 是 `Fractional Index` 的十六进制字符串。事件会按照因果顺序触发。删除事件表示目标节点及其整棵子树被删除，子节点不会单独发出删除事件。

### 节点数据的事件

树节点的数据使用 `MapContainer` 表示，因此与节点关联的每个 `MapContainer` 都是 `TreeContainer` 的子容器。如果修改了某个节点的数据，会收到来自该 `MapContainer` 的事件，并且事件路径中会包含一个 `TreeID`，指明是哪一个节点的数据发生变化。

## 获取全部节点

可以通过多种方式从 `LoroTree` 中获取节点：

1. `nodes()`：返回当前 `LoroTree` 中的全部 `LoroTreeNode`，但不保证顺序。
2. `roots()`：返回所有有序的根节点，随后可通过 `LoroTreeNode` 的 `children()` 方法继续层级遍历。
3. `toArray()`：以层级遍历顺序返回所有节点，节点结构如下：

   ```ts no_run twoslash
   import { TreeID, LoroMap } from "loro-crdt";
   // ---cut---
   {
     id: TreeID;
     parent: TreeID | undefined;
     index: number;
     fractionalIndex: string;
     meta: LoroMap;
   }
   ```

4. `toJSON()`：`toArray()` 的 JSON 版本，同时会将 `meta` 递归转换成 JSON。

## 基本用法

### 示例

```ts no_run twoslash
import { LoroDoc, LoroTree, LoroTreeNode, LoroMap } from "loro-crdt";
// ---cut---
let doc = new LoroDoc();
let tree: LoroTree = doc.getTree("tree");
let root: LoroTreeNode = tree.createNode();
// 默认追加到父节点子列表末尾
let node = root.createNode();
// 显式指定插入位置
let node2 = root.createNode(0);
// 将节点移动为另一个节点的子节点
node.move(node2);
// 在新父节点中指定位置
node.move(node2, 0);
// 将节点移为根节点
node.move();
// 将节点移动到另一个节点之后
node.moveAfter(node2);
// 将节点移动到另一个节点之前
node.moveBefore(node2);
// 获取节点在父节点子列表中的索引
let index = node.index();
// 获取节点的分数索引值
let fractionalIndex = node.fractionalIndex();
// 访问节点关联的 Map 容器
let nodeData: LoroMap = node.data;
```
