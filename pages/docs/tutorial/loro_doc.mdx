# LoroDoc 入门

LoroDoc 是使用 Loro 的主要入口，负责容器管理、版本控制、事件系统以及导入导出等功能。

它提供：

1. **容器管理**——创建并管理 Text、List、Map、Tree、MovableList 等 CRDT 容器
2. **版本控制**——追踪历史、检出版本、管理分支
3. **事件系统**——订阅文档级或容器级的变更
4. **导入导出**——以多种格式保存与加载文档或增量

## 基础用法

首先创建一个 LoroDoc 实例：

```ts twoslash
import {
  LoroDoc,
  LoroText,
  LoroList,
  LoroMap,
  LoroTree,
  LoroMovableList,
} from "loro-crdt";
// ---cut---
// 使用随机 PeerID 创建文档
const doc = new LoroDoc();

// 也可以设置固定 PeerID
doc.setPeerId("1");

// 获取各类容器
const text = doc.getText("text");
const list = doc.getList("list");
const map = doc.getMap("map");
const tree = doc.getTree("tree");
const movableList = doc.getMovableList("tasks");
```

假设要建模如下结构：

```json
{
  "meta": {
    "title": "Document Title",
    "createdBy": "Author"
  },
  "content": "Article",
  "comments": [
    {
      "user": "userId",
      "comment": "comment"
    }
  ]
}
```

```ts twoslash
import { LoroDoc, LoroMap } from "loro-crdt";
// ---cut---
const doc = new LoroDoc();
const meta = doc.getMap("meta");
meta.set("title", "Document Title");
meta.set("createdBy", "Author");
doc.getText("content").insert(0, "Article");
const comments = doc.getList("comments");
const comment1 = comments.insertContainer(0, new LoroMap());
comment1.set("user", "userId");
comment1.set("comment", "comment");
```

## 支持的数据类型（LoroValue）

`LoroValue` 表示 Loro 容器可直接存储的类型：

```ts
type LoroValue =
  | null
  | boolean
  | number
  | string
  | Uint8Array
  | LoroValue[]
  | { [key: string]: LoroValue };
```

### 存储不同数据类型的示例

```ts twoslash
import { LoroDoc } from "loro-crdt";
// ---cut---
const doc = new LoroDoc();
const map = doc.getMap("data");

// 基本类型
map.set("name", "Alice");
map.set("age", 30);
map.set("score", 95.5);
map.set("isActive", true);
map.set("metadata", null);

// 二进制数据
map.set("bytes", new Uint8Array([1, 2, 3, 4, 5]));

// 嵌套对象
map.set("profile", {
  email: "alice@example.com",
  settings: {
    theme: "dark",
    notifications: true,
  },
});

// 数组
map.set("tags", ["javascript", "typescript", "loro"]);

// 混合结构
map.set("complex", {
  items: [1, 2, { nested: true }],
  binary: new Uint8Array([255, 128]),
  active: false,
});
```

> 如果需要在容器内嵌套另一个 CRDT 容器（例如 LoroText、LoroList），请使用 `setContainer()` 或 `insertContainer()`，而不是普通的 `set`/`insert`。

## 容器类型

LoroDoc 支持以下容器：

1. **Text**：富文本编辑
2. **List**：有序集合
3. **Map**：键值对
4. **Tree**：树形结构
5. **MovableList**：可移动列表

### Text

```ts twoslash
import { LoroDoc } from "loro-crdt";
// ---cut---
const doc = new LoroDoc();
const text = doc.getText("text");
text.insert(0, "Hello");
text.insert(5, " World!");
console.log(text.toString()); // "Hello World!"

// 富文本
doc.configTextStyle({
  bold: { expand: "after" },
  link: { expand: "none" },
});
text.mark({ start: 0, end: 5 }, "bold", true);
```

### List

```ts twoslash
import { LoroDoc, LoroText } from "loro-crdt";
// ---cut---
const doc = new LoroDoc();
const list = doc.getList("list");
list.insert(0, "first");
list.insert(1, "second");
console.log(list.toArray()); // ["first", "second"]

const nestedText = list.insertContainer(2, new LoroText());
nestedText.insert(0, "nested text");
```

### Map

```ts twoslash
import { LoroDoc, LoroText } from "loro-crdt";
// ---cut---
const doc = new LoroDoc();
const map = doc.getMap("map");
map.set("name", "John");
map.set("age", 30);
console.log(map.get("name")); // "John"

const userText = map.setContainer("bio", new LoroText());
userText.insert(0, "Software Engineer");
```

### Tree

```ts twoslash
import { LoroDoc } from "loro-crdt";
// ---cut---
const doc = new LoroDoc();
const tree = doc.getTree("tree");
const root = tree.createNode();
root.data.set("name", "Root");

const child1 = root.createNode();
child1.data.set("name", "Child 1");

const child2 = root.createNode();
child2.data.set("name", "Child 2");
```

### MovableList

```ts twoslash
import { LoroDoc } from "loro-crdt";
// ---cut---
const doc = new LoroDoc();
const movableList = doc.getMovableList("tasks");
movableList.insert(0, "Task 1");
movableList.insert(1, "Task 2");
movableList.move(0, 1); // 将 Task 1 移到 Task 2 之后
```

## 协作同步

```ts no_run twoslash
import { LoroDoc } from "loro-crdt";
declare const otherDoc: LoroDoc;
// ---cut---
const doc1 = new LoroDoc();
doc1.setPeerId("1");
const text1 = doc1.getText("text");

const doc2 = new LoroDoc();
doc2.setPeerId("2");
const text2 = doc2.getText("text");

doc1.subscribeLocalUpdates((updates) => {
  doc2.import(updates);
});

doc2.subscribeLocalUpdates((updates) => {
  doc1.import(updates);
});

text1.insert(0, "Hello");
doc1.commit();
await Promise.resolve();
text2.insert(5, " World!");
doc2.commit();
```

## 撤销 / 重做

```ts twoslash
import { UndoManager, LoroDoc } from "loro-crdt";
// ---cut---
const doc = new LoroDoc();
const undoManager = new UndoManager(doc, {
  maxUndoSteps: 100,
  mergeInterval: 1000,
});

const text = doc.getText("text");
text.insert(0, "Hello");
doc.commit();

if (undoManager.canUndo()) {
  undoManager.undo();
}
if (undoManager.canRedo()) {
  undoManager.redo();
}
```

### 浅快照

```ts twoslash
import { LoroDoc } from "loro-crdt";
// ---cut---
const doc = new LoroDoc();
const shallowSnapshot = doc.export({
  mode: "shallow-snapshot",
  frontiers: doc.oplogFrontiers(),
});

const isShallow = doc.isShallow();
const sinceVersion = doc.shallowSinceVV();
const sinceFrontiers = doc.shallowSinceFrontiers();
```

> 浅快照只包含某一版本点之后的历史，适合减小数据体积或隐藏旧历史。

### 脱敏敏感内容

```ts no_run twoslash
import { LoroDoc, redactJsonUpdates } from "loro-crdt";
// ---cut---
const doc = new LoroDoc();
doc.setPeerId("1");

const text = doc.getText("text");
text.insert(0, "Sensitive information");
doc.commit();

const map = doc.getMap("map");
map.set("password", "secret123");
map.set("public", "public information");
doc.commit();

const jsonUpdates = doc.exportJsonUpdates();
const versionRange = {
  "1": [0, 21],
};
const redactedJson = redactJsonUpdates(jsonUpdates, versionRange);
const redactedDoc = new LoroDoc();
redactedDoc.importJsonUpdates(redactedJson);

console.log(redactedDoc.getText("text").toString());
// "���������������������"
```

脱敏会替换文本为占位符，Map/List 插入值为 `null`，但保留结构与元数据。若需彻底移除历史，请结合浅快照。

> 记得将脱敏后的文档同步给所有节点，否则仍可能存在包含敏感信息的旧副本。

## 订阅事件

```ts no_run twoslash
import { LoroDoc } from "loro-crdt";
// ---cut---
const doc = new LoroDoc();
doc.subscribe((event) => {
  console.log("Document changed:", event);
});

text.subscribe((event) => {

});
```

### 事件触发

事件在事务提交后、微任务结尾时触发：

```ts no_run twoslash
import { LoroDoc } from "loro-crdt";
// ---cut---
const doc = new LoroDoc();
const text = doc.getText("text");

doc.subscribe((event) => {
  console.log("Change event:", event);
});

text.insert(0, "Hello");
doc.commit();
await Promise.resolve();
```

导出、导入、checkout 等操作会隐式提交：

```ts no_run twoslash
import { LoroDoc } from "loro-crdt";
declare const someData: Uint8Array;
declare const someVersion: any;
// ---cut---
const doc = new LoroDoc();

doc.export({ mode: "snapshot" });
doc.import(someData);
doc.checkout(someVersion);
```

提交时可以携带额外信息：

```ts no_run twoslash
import { LoroDoc } from "loro-crdt";
// ---cut---
const doc = new LoroDoc();
doc.commit({
  origin: "user-edit",
  message: "Add greeting",
  timestamp: Date.now(),
});
await Promise.resolve();
```

## 版本控制与历史

### 版本表示

1. **版本向量**（peer → counter）：

```ts twoslash
import { LoroDoc } from "loro-crdt";
// ---cut---
const doc = new LoroDoc();
const vv = doc.version();
const oplogVv = doc.oplogVersion();
```

2. **Frontiers**（各 peer 最新操作 ID，通常只有 1 个元素）：

```ts twoslash
import { LoroDoc } from "loro-crdt";
// ---cut---
const doc = new LoroDoc();
doc.setPeerId("0");
doc.getMap("map").set("text", "Hello");
const frontiers = doc.frontiers();
const oplogFrontiers = doc.oplogFrontiers();
```

### checkout 与时光旅行

```ts twoslash
import { LoroDoc } from "loro-crdt";
// ---cut---
const doc = new LoroDoc();
const frontiers = doc.frontiers();
const text = doc.getText("text");
text.insert(0, "Hello World!");

doc.checkout(frontiers);
doc.checkoutToLatest();
// 或 doc.attach();
```

checkout 后文档进入 detached 状态：默认不可编辑、导入的操作不会立即应用，需要 `attach()` 回到最新版本。

可以显式控制 detached：

```ts twoslash
import { LoroDoc } from "loro-crdt";
// ---cut---
const doc = new LoroDoc();
console.log(doc.isDetached()); // false

doc.detach();
console.log(doc.isDetached()); // true

doc.attach();
console.log(doc.isDetached()); // false

doc.setDetachedEditing(true);
console.log(doc.isDetachedEditingEnabled()); // true
```

#### 导入行为

```ts twoslash
import { LoroDoc } from "loro-crdt";
// ---cut---
const oldDoc = new LoroDoc();
oldDoc.getMap("map").set("name", "John");
const updates = oldDoc.export({ mode: "update" });
const doc = new LoroDoc();

doc.import(updates); // 若处于 detached，仅记录，不立即应用
doc.checkoutToLatest(); // 应用更新
```

#### fork

```ts twoslash
import { LoroDoc } from "loro-crdt";
// ---cut---
const doc = new LoroDoc();
doc.setPeerId("0");
doc.getText("text").insert(0, "Hello");
const forkedDoc = doc.fork();
const forkedAtVersion = doc.forkAt([{ peer: "0", counter: 1 }]);
console.log(forkedAtVersion.getText("text").toString()); // "He"
```

## 高级能力

### 稳定光标

```ts twoslash
import { LoroDoc } from "loro-crdt";
// ---cut---
const doc = new LoroDoc();
const text = doc.getText("text");
text.insert(0, "123");

const cursor = text.getCursor(0, 0);
if (cursor) {
  const pos = doc.getCursorPos(cursor);
  console.log(pos.offset);
  console.log(pos.side);

  text.insert(0, "abc");
  const newPos = doc.getCursorPos(cursor);
  console.log(newPos.offset);
}
```

### 变更追踪

```ts twoslash
import { LoroDoc, OpId } from "loro-crdt";
// ---cut---
const doc = new LoroDoc();
doc.setPeerId("1");
doc.getText("text").insert(0, "Hello");
doc.commit();
console.log(doc.changeCount());
console.log(doc.opCount());

const changes = doc.getAllChanges();
for (const [peer, peerChanges] of changes.entries()) {
  for (const change of peerChanges) {
    console.log({
      peer: change.peer,
      counter: change.counter,
      lamport: change.lamport,
      timestamp: change.timestamp,
      message: change.message,
    });
  }
}

const changeId = { peer: "1", counter: 0 } as OpId;
const change = doc.getChangeAt(changeId);
const ops = doc.getOpsInChange(changeId);

doc.travelChangeAncestors([changeId], (change) => {
  console.log("Ancestor:", change);
  return true;
});

const modifiedContainers = doc.getChangedContainersIn(changeId, 1);
```

### 导入 / 导出模式

```ts twoslash
import { LoroDoc } from "loro-crdt";
// ---cut---
const doc = new LoroDoc();
const previousVersion = doc.version();
doc.getText("text").insert(0, "Hello");
const snapshot = doc.export({ mode: "snapshot" });
const updates = doc.export({ mode: "update", from: previousVersion });
const shallowSnapshot = doc.export({
  mode: "shallow-snapshot",
  frontiers: doc.oplogFrontiers(),
});
const rangeUpdates = doc.export({
  mode: "updates-in-range",
  spans: [{ id: { peer: "1", counter: 0 }, len: 10 }],
});

const status = doc.import(updates);
console.log(status.success);
console.log(status.pending);

const status2 = doc.importBatch([snapshot, updates]);

const jsonStatus = doc.importJsonUpdates({
  schema_version: 1,
  start_version: new Map([["1", 0]]),
  peers: ["1"],
  changes: [],
});
```
