# 示例

你可以在 [Loro 的 Deno 示例仓库](https://github.com/loro-dev/loro-examples-deno)中找到基础用法示例。

### loro-prosemirror

GitHub: [loro-dev/loro-prosemirror](https://github.com/loro-dev/loro-prosemirror)

该项目让 Loro 与 ProseMirror（功能强大的富文本编辑器框架）无缝集成，支持：

- 搭配富文本的文档状态同步
- 光标感知与同步
- 协作编辑中的撤销 / 重做

它也可以与基于 ProseMirror 的热门富文本编辑器 [Tiptap](https://tiptap.dev/) 搭配，让你轻松为 Tiptap 应用添加协作能力。

### loro-codemirror

GitHub: [loro-dev/loro-codemirror](https://github.com/loro-dev/loro-codemirror)

该包提供 Loro 与 CodeMirror 6（多才多艺的代码编辑器）的集成，支持：

- 文档状态同步
- 光标感知同步
- 撤销 / 重做功能
